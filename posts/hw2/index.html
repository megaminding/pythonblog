Implementation of parse(self, response)

This method navigates you to the Full Cast & Crew page. It does so by obtaining the starting url and appending “cast”. This is hard coding. We then make a request to that link with a callback to the method parse_full_credits by using yielded scrapy.Request.

import inspect
from TMDB_scraper.TMDB_scraper.spiders.tmdb_spider import TmdbSpider
print(inspect.getsource(TmdbSpider.parse)) 
    def parse(self, response):
        '''
        This method navigates to the Full Cast & Crew page

        Args: response
        Yields: Request (naviation to the Full Cast & Crew page)
        Returns: NA (this method does not return any data)
        We can hard this part by obtaining the starting url and appending the word "cast".
        We then call the parse_full_credits(self,response), by specifying this method in the 
        callback argument to a yielded scrapy.Request. 
        '''
        ### navigate to the Full Cast & Crew page by taking starting url and appending "cast" (hard code method)
        yield scrapy.Request(url=self.start_urls[0] + "cast", callback=self.parse_full_credits) #callback to the method parse_full_credits by using yielded scrapy.Request

Implementation of parse_full_credits(self, response)

This method yields a scrapy.Request for the page of each actor listed on the page. This method works by obtaining the ordered list of crew by using response.css("ol.people.credits"). To get just the actors/cast, we index the 0th element because that’s the first section. Within each list, we enter the div called “info” and obtain the link. With this link, we append it to the base url and call the parse_actor_page(self,response), by specifying this method in the callback argument to a yielded scrapy.Request. We do this for all the links using list comprehension that is applied to the array of actor links.

import inspect
from TMDB_scraper.TMDB_scraper.spiders.tmdb_spider import TmdbSpider
print(inspect.getsource(TmdbSpider.parse_full_credits)) 
    def parse_full_credits(self, response):
        '''
        This method yields a scrapy.Request for the page of each actor listed on the page

        Args: response
        Yields: Request (naviation to each actor page)
        Returns: NA (this method does not return any data)
        
        The yielded request should specify the method parse_actor_page(self, response) should be called when the actor’s page is reached. 
        We obtain the ordered list of crew. To get just the actors/cast, we index the 0th element because that's the first section. 
        Within each list, we enter the div called "info" and obtain the link. With this link, we append it to the base url and 
        call the parse_actor_page(self,response), by specifying this method in the 
        callback argument to a yielded scrapy.Request. 
        '''       
        links = []
        actors = response.css("ol.people.credits")[0] #obtains the ordered list of crew. we index the 0th element to obtain just the actors/cast
        links = (actors.css("li div.info a::attr(href)").getall())   ## obtain a link associated with each actor
        yield from [scrapy.Request(url="https://www.themoviedb.org" + link, callback=self.parse_actor_page) for link in links]  #callback to the method parse_actor_page by using yielded scrapy.Request

Implementation of parse_actor_page(self, response):

This method yields a dictionary containing the actor name and the name of the movie/TV show for each of the movies or TV shows on which that actor has worked in an “Acting” role. This method works by obtaining the actor’s name using css selectors, grabbing the h2 title. We search through all the h3 texts, looking for the one that says “Acting” and then we want to access the next selector containing the list of movies/shows. We then specify what exactly we want from the next selector which is the bdi. We make a set to ensure that all the entries are unique and there are no duplicates. Then we yield a dictionary containing the actor name and the name of the movie/TV show for each of the movies or TV shows on which that actor has worked in an “Acting” role.

import inspect
from TMDB_scraper.TMDB_scraper.spiders.tmdb_spider import TmdbSpider
print(inspect.getsource(TmdbSpider.parse_actor_page)) 
    def parse_actor_page(self, response):
        '''
        We start at the actor page. This method yields a dictionary containing the actor name and the name of the movie/TV show for each of the movies or TV shows on which that actor has worked
        in an “Acting” role.

        Args: response
        Yields: dictionary with two key-value pairs, of the form {"actor" : actor_name, "movie_or_TV_name" : movie_or_TV_name}
        
        We obtain the actor's name using css selectors, grabbing the h2 title. We search through all the h3 texts, looking for the one that says
        "Acting" and then we want to access the next selector containing the list of movies/shows. We then specify what exactly 
        we want from the next selector which is the bdi. We make a set to ensure that all the entries are unique and there are no duplicates. 
        Then we yield a dictionary containing the actor name and the name of the movie/TV show for each of the movies or TV shows on which that actor has worked
        in an “Acting” role.
        '''  
        actor_name =response.css("h2.title a::text").get() #obtain actor name
        for i in response.css("h3::text").getall(): #search thru all headers
            if i == "Acting": #check if header matches Acting
                next_selector = response.css("h3:contains('Acting') + *") #grab next selector after identifying Acting header
                list_of_shows = (next_selector.css("bdi::text").getall()) #obtain all shows and store in array
                unique_list_of_shows = set(list_of_shows) #remove duplicates
                for show in unique_list_of_shows: #iterate thru the shows 
                    yield { #dictionary with two key-value pairs, of the form {"actor" : actor_name, "movie_or_TV_name" : movie_or_TV_name}
                        "actor" : actor_name,
                        "movie_or_TV_name": show,
                    }

Grouping Results

Now we want to edit the table in such a way where we can see which movie/TV show are most reccomended, based on which ones have the highest number of actors from the first Harry Potter movie. We want to have a table where the first column in the movie/TV name- this is essentially a list of unique movies. Then in the second column, it corresponds with that movie/TV and has the number of actors featured in it.

To execute this, we can apply the groupby function to the column movie_or_TV_name. We apply the functions size and reset index in order to create a new row that has the size of the movie_or_TV_name, which means the number of actors featured in that movie. We add the parameter name="actor_count" to give the new column the appropriate name. Then we order it from highest to smallest based on actor_count to show users the reccomended movies with the highest actor count.

grouped_df = df.groupby("movie_or_TV_name").size().reset_index(name="actor_count") # use groupby to make a new column that counts the number of actors featured in each movie/TV 
grouped_df = grouped_df.sort_values(by='actor_count', ascending = False) # order it from highest to smallest based on actor_count to show users the reccomended movies with the highest actor count.

Creating a Graph based on the Table

Now we can create a visualization by importing plotly. We want to create a histogram showing the top 20 reccomended movies based on number of actors from the first Harry Potter featured in it. The x axis is the movie_or_TV_name and the y axis is the actor_count.

We also need to add titles.

from plotly import express as px
import plotly.io as pio
pio.renderers.default="iframe"
fig = px.histogram(grouped_df[:20],
              x = "movie_or_TV_name", #each bar represents each movie
              y = "actor_count", #height of each bar represents the number of actors
              )

fig.update_layout(title=f"Reccomended movies based on number of actors from the first Harry Potter featured in it", # set title
                        yaxis_title="Number of Actors from HP 1",#set yaxis title
      xaxis_title="Movies Featuring Harry Potter One Actors", #set xaxis title
              )
fig.show()
