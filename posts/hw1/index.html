Query Function

Next, we want to make a query function that will take in certain arguments and filter the data to produce a Pandas dataframe of temperature readings for the specified country, in the specified date range, in the specified month of the year. We are importing the function from a different python file for this to work.

from climate_database import query_climate_database
print(inspect.getsource(query_climate_database)) #show the content of the functions you defined in a separate python file
def query_climate_database( db_file, country, year_begin, year_end, month):
    """Makes SQL query and outputs the data based on specific arguments

    Args:
        db_file (db): the file name for the database
        country (string): the name of a country for which data should be returned.
        year_begin (int):  the earliest years for which should be returned (inclusive).
        year_end (int): the latest years for which should be returned (inclusive).
        month (int): the month of the year for which should be returned.

    Returns:
        a Pandas dataframe of temperature readings for the specified country, 
        in the specified date range, in the specified month of the year. 
        This dataframe should have the following columns, in this order:

            NAME: The station name.
            LATITUDE: The latitude of the station.
            LONGITUDE: The longitude of the station.
            Country: The name of the country in which the station is located.
            Year: The year in which the reading was taken.
            Month: The month in which the reading was taken.
            Temp: The average temperature at the specified station during the specified year and month.
    """
   
    with sqlite3.connect(db_file) as conn:
        cmd = \
        f'''
        SELECT
        stations.name, latitude, longitude, countries.name as Country, year, month, temp  FROM temperatures
        INNER JOIN  stations on temperatures.ID = stations.ID --merging stations and temperatures 
        INNER JOIN countries ON SUBSTR(stations.ID, 1, 2) = countries."FIPS 10-4" --merging countries and temperatures 
        WHERE year >= {year_begin} AND year <= {year_end} AND month == {month}  AND countries.Name = '{country}'
        ORDER BY stations.name, year
        
        '''
        df = pd.read_sql_query(cmd, conn)
    return (df)

Geographic Scatter Function for Yearly Temperature Increases

Now let’s make an interactive geographic scatterplot using Plotly Express. Each point represents each station where the color of the point reflects an estimate of the yearly change in temperature during the specified month and time period at that station. We can do this using the first coefficient of a linear regression model at that station. First let’s build our coef function that creates a best fit line based on Year and Temp for a particular data group.

Next, we want to use that coef function by doing df.groupby(["NAME", "Month"]).apply(coef), which the yearly change in temperature during the specified month and time period at that station. After, we merge that data with the df and change the column name to something more descriptive.

With that, we can start to build out plot.

def coef(data_group): #obtain first coefficient of a linear regression model of  the yearly change in temperature during the specified month and time period at that station.
    x = data_group[["Year"]] # 2 brackets because X should be a df
    y = data_group["Temp"]   # 1 bracket because y should be a series
    LR = LinearRegression()
    LR.fit(x, y)
    return LR.coef_[0] # first coeff
def temperature_coefficient_plot(db_file, country, year_begin, year_end, month, min_obs, **kwargs):
    """Makes temperature coefficient plot

    Args:
        db_file (db): the file name for the database
        country (string): the name of a country for which data should be returned.
        year_begin (int):  the earliest years for which should be returned (inclusive).
        year_end (int): the latest years for which should be returned (inclusive).
        month (int): the month of the year for which should be returned.
        min_obs(int): the minimum required number of years of data for any given station
        **kwargs: additional keyword arguments passed to px.scatter_mapbox() (control the colormap used, the mapbox style, etc)

    Returns:
         an interactive geographic scatterplot, constructed using Plotly Express, with a point for each station, 
         such that the color of the point reflects an estimate of the yearly change in temperature during the 
         specified month and time period at that station.
    """
    df = query_climate_database(db_file, country, year_begin, year_end, month) 
    
    # Only data for stations with at least min_obs years worth of data in the specified month should be plotted;
    # the others should be filtered out
    count = df.groupby(["NAME"])["Year"].transform("count") # for each station, we count the number of unique years
    df = df[count >= min_obs] # we filter out the stations where the number of unique years isn't equal to or greater than min_obs

    # for the plot, the color of the point reflects an estimate of the yearly change in temperature during the specified month and 
    # time period at that station. A reasonable way to do this is to compute the first coefficient of a linear regression
    # model at that station, as illustrated in the lecture where we used the .apply() method.
    coefs = df.groupby(["NAME", "Month"]).apply(coef) 
    coefs = coefs.reset_index()
    coefs.rename(columns={0: 'Estimated Yearly Increase (in Celcius)'}, inplace=True) #The colorbar and overall plot have professional titles.
    coefs["Estimated Yearly Increase (in Celcius)"] = round( coefs["Estimated Yearly Increase (in Celcius)"], 4) #he estimates shown in the hover are rounded to a sober number of significant figures.
  
    
    coefs = pd.merge(coefs, df, on="NAME")
    fig = px.scatter_mapbox(coefs,
                        lat = "LATITUDE",
                        lon = "LONGITUDE",
                        hover_name = "NAME",
                        color = "Estimated Yearly Increase (in Celcius)",
                        color_continuous_scale = kwargs.get("color_continuous_scale") or 'RdGy_r', #using kwargs if available
                        zoom = kwargs.get('zoom') or 2, #using kwargs if available
                       )

    

    # The colorbar is centered at 0, so that the “middle” of the colorbar (white, in this case) corresponds to a coefficient of 0.
    abs_max = max(abs(coefs["Estimated Yearly Increase (in Celcius)"].min()), abs(coefs["Estimated Yearly Increase (in Celcius)"].max()))
    
    fig.update_layout(mapbox_style=kwargs.get("mapbox_style") or "carto-positron",
                       title=f"Estimates of yearly increase in temperature in {calendar.month_name[month]} for stations in {country}, years {year_begin} - {year_end}", #The colorbar and overall plot have professional titles.
                       coloraxis=dict(cmin=-abs_max, cmax=abs_max)) # Set cmin and cmax to center the colorbar at 0
    return fig
color_map = px.colors.diverging.RdGy_r # choose a colormap

def one_more_query(db_file, station_name_one,station_name_two, temp_begin, temp_end ):
    """Makes SQL query and outputs the data based on specific arguments

    Args:
        db_file (db): the file name for the database
        station_name_one (string): the name of a station for which data should be returned.
        station_name_two (string): the name of a second station for which data should be returned.
        temp_begin (int):  the lowest temps for which should be returned (inclusive).
        temp_end (int): the highest temps for which should be returned (inclusive).

    Returns:
        a Pandas dataframe of temperature readings for the specified country, 
        in the specified date range, in the specified month of the year. 
        This dataframe should have the following columns, in this order:

            NAME: The station name.
            Country: The name of the country in which the station is located.
            Year: The year in which the reading was taken.
            Month: The month in which the reading was taken.
            Temp: The average temperature at the specified station during the specified year and month.
            STNELEV: the standard elevation at the specific station
    """
    with sqlite3.connect(db_file) as conn:
        cmd = \
        f'''
        SELECT
        stations.name, countries.name as Country, year, month, temp, stations.STNELEV  FROM temperatures
        INNER JOIN  stations on temperatures.ID = stations.ID --merging stations and temperatures 
        INNER JOIN countries ON SUBSTR(stations.ID, 1, 2) = countries."FIPS 10-4" --merging countries and temperatures 
        WHERE temp >= {temp_begin} AND temp <= {temp_end} AND (stations.name == '{station_name_one}' or stations.name == '{station_name_two}') 
        ORDER BY stations.name, year
        
        '''
        df = pd.read_sql_query(cmd, conn)
    return (df)

Temperature Histogram Function for Two Different Stations

Now let’s make an interactive temperature histogram using Plotly Express. Each bar represents each month where the height of the bar reflects an average monthly temperature. We can compare the two stations side by side. The temperatures are limited to a range set by the user. This is a good way of not including outliers. This function will create a visualizations that addresses the following question:

Question: How does the average monthly temperature vary over the course of a year when comparing two different stations?

def temperature_histogram_plot(db_file, station_name_one,station_name_two, temp_begin, temp_end):
  """Makes temperature histogram chart comparing two different stations within range of temps

    Args:
        db_file (db): the file name for the database
        station_name_one (string): the name of a station for which data should be returned.
        station_name_two (string): the name of a second station for which data should be returned.
        temp_begin (int):  the earliest temps for which should be returned (inclusive).
        temp_end (int): the latest temps for which should be returned (inclusive).

    Returns:
         an interactive histogram, constructed using Plotly Express, where each month bar represents the average 
         monthly temperature, for a given station using only temperatures within the 
         specific range. compares two different stations side by side
    """
    #obtaining dataframe using query of specific parameters
  df = one_more_query(db_file = db_file, # the file name for the database
                       station_name_one =station_name_one, # the name of a station for which data should be returned.
                       station_name_two = station_name_two, # the name of a second station for which data should be returned.
                       temp_begin = temp_begin, # the lowest temps for which should be returned (inclusive).
                       temp_end = temp_end, # the highest temps for which should be returned (inclusive)
  )
  fig = px.histogram(df,
              x = "Month", #each bar represents the monthly data
              y = "Temp", #height of each bar represents the temp
              histfunc="avg", #we take the average of the temperature for each month 
              facet_col="NAME", #we create two different columns for the two different stations
              )


  fig.update_layout(
      title=f"Monthly Avg Temp for two stations ({station_name_one} and {station_name_two}) using temp data within the range {temp_begin} - {temp_end}", #The colorbar and overall plot have professional titles.
      yaxis_title="Monthly Avg Temp (in Celcius)",
      )
  return fig
