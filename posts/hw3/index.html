Python functions for database management in the app

Now let’s make a database to keep track of all the messages. There’s two functions we need to write: one to get the database and the second to insert messages into the database.

Create the Database

Our first step is to create the database. The function get_message_db is used to create the database of messages and return it. The first thing it does is check whether there is a database called message_db defined in the global scope. If not, assign the global variable message_db to the connected database using message_db = sqlite3.connect("messages_db.sqlite"). After, it creates a table called messages if it doesn’t exist using SQL CREATE TABLE IF NOT EXISTS messages (handle text, messages text). Then it returns the database.

import sqlite3
import pandas as pd
message_db = None #initialize 
def get_message_db():
    global message_db #creating global variable so that it can be accessed outside the function's scope
    if message_db:
        return message_db #return already existing database
    else: #logic if database doesn't exist
        message_db = sqlite3.connect("messages_db.sqlite", check_same_thread=False) #connect to "messages_db.sqlite"
        cmd = 'CREATE TABLE  IF NOT EXISTS messages (handle text, messages text)' #create table with a handle column (text) and a message column (text)
        cursor = message_db.cursor() #variable for cursor
        cursor.execute(cmd) #execute command
        message_db.commit() #ensure work has been saved
        message_db.close() #close connection within function
        return message_db #return newly created database

Insert Messages into Database

Now that we have our database and table ready, it’s time to add messages into it. First we build our function definition and allow it to take in the parameters handle and message. Then let’s connect it to the database. We can execute a command that adds into the messages table, specifiying the column names which are handle and messages. We want to insert the corresponding values for those two columns——in this case, those values are our variable names handle and message. Then we execute the cursor, commmit, and close the database. Ta-da!

To add error handling, we use the try and except blocks to handle errors and exceptions during program execution. If everything is successful, it’ll return a True boolean, but if not, it’ll return the error message, which we can later use to print out to users so they know what went wrong.

import sqlite3
import pandas as pd
def insert_message(handle, message):
    get_message_db()
    try: 
        message_db = sqlite3.connect("messages_db.sqlite", check_same_thread=False) #connect it to database
        cmd = f'''
    INSERT INTO messages ( handle, messages)
    VALUES ('{handle}', '{message}');
        ''' 
        cursor = message_db.cursor()
        cursor.execute(cmd)
        message_db.commit() #when working directly with SQL commands, it is necessary to run db.commit() after inserting a row into db in order to ensure that your row insertion has been saved.
        message_db.close() #Close the database connection within the function!
        print(handle, message)
        return True
    except sqlite3.Error as e:
        return e

Creating Submit Functionality

After a user submits their message, we want this message and handle to be added into the database for storage.

Because we want the user’s input to have an interaction with the rest of our app, we use callbacks, which are chainable functions that are automatically called whenever a UI element is changed. In this case, the app looks for changes in our input which is our submit button; when a user wants to submit their text, they click the submit button which carries a sequence of events. It captures the two states for the two different text area values, which then is reflected in the text area and confirms what the user’s message and handle was.

How do we add it to the database? We use our function insert_message which takes the arguments handle and message to add it to the database. This function takes care of error handling using the try and except blocks to handle errors and exceptions during program execution. We check if the return value of the function is a True boolean, and if it is, then we’ll print out the message and handle, but if not, it’ll return the error message to let users know what went wrong. The insert_message is triggered during the callbacks when the user hits the submit button, which is our input. This results in the attempt to insert the message into the database and then the printing of the user confirmation or the error message.

View Random Submissions

Now, let’s create a function random_messages(n), which will return a collection of as many random messages of up to size n from the message_db. It connects to the message database, selects as many random messages and handles from the database of up to size n. 

To add error handling, we use the try and except blocks to handle errors and exceptions during program execution. If everything is successful, it’ll return a df, but if not, it’ll return the error message, which we can later use to print out to users so they know what went wrong.

def random_messages(n):
    try: 
        with sqlite3.connect("messages_db.sqlite") as conn: #connects to message database
            df = pd.read_sql_query(f"SELECT * FROM messages ORDER BY RANDOM() LIMIT {n};", conn) #selects as many random messages and handles of up to size n
            return(df) #returns this dataframe
    except Exception as e: #error handling
        return e #returns error message
