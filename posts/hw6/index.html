Function make_dataset

Here, we are building a function called make_dataset which will change the text to lowercase, remove stopwords from the article text and title, and construct and return a tf.data.Dataset with two inputs and one output.

def standardization(text):
    text = text.lower() #lower case
    text = re.sub(f"[{string.punctuation}]", "", text)  #remove punctuation
    text = " ".join(word for word in text.split() if word not in stop_words) #remove stop words
    return text

def make_dataset(df):
    df["title"] = df["title"].apply(standardization) #apply to title
    df["text"] = df["text"].apply(standardization) #apply to text
    
    dataset = tf.data.Dataset.from_tensor_slices((
        {"title": df["title"].values, "text": df["text"].values}, # The input should be of the form (title, text)
        df["fake"].values # the output should consist only of the fake column
    ))
    
    dataset = dataset.batch(100) #Batching causes your model to train on chunks of data rather than individual rows.
    
    return dataset
data = make_dataset(df)

Preparing a text vectorization layer for tf model

size_vocabulary = 2000

def standardization(input_data):
    lowercase = tf.strings.lower(input_data) #make lowercase
    no_punctuation = tf.strings.regex_replace(lowercase, #remove punctuation
                                  '[%s]' % re.escape(string.punctuation),'')
    return no_punctuation 

title_vectorize_layer = TextVectorization(
    standardize=standardization,
    max_tokens=size_vocabulary, # only consider this many words
    output_mode='int',
    output_sequence_length=500) 

title_vectorize_layer.adapt(train.map(lambda x, y: x["title"]))

Base Rate

Let’s calculate the Base Rate which is the accuracy of a model that always makes the same guess. Let’s calculate the base rate by examining the labels on the training set. We can do this by getting the proportion of fake values out of entire data set.

one, zero = df['fake'].value_counts()
base_rate = max(one, zero) / len(df) #bigger proportion of fake or nonfake values out of entire data set

First Model using Article Title

Let’s use a Keras functional model for this. We’ll apply embedding so we can create a visualization later on.

title_input = keras.Input(
    shape = (1,),
    name = "title",
    dtype = "string"
)

title_features = title_vectorize_layer(title_input)# maps text features to integer sequences
title_features = layers.Embedding(size_vocabulary, 3, name = "embedding_title_features")(title_features) #Embedding layer creates embedding vectors out of the input words
title_features = layers.Dropout(0.2)(title_features)#prevent overfitting
title_features = layers.GlobalAveragePooling1D()(title_features) #Average pooling for temporal data
title_features = layers.Dropout(0.2)(title_features)#prevent overfitting
title_features = layers.Dense(32, activation='relu')(title_features) #connects every neuron in a layer to every neuron in the previous layer
output = layers.Dense(2, name = "fake")(title_features) #connects every neuron in a layer to every neuron in the previous layer
model1 = keras.Model(
    inputs = [title_input], #model with just title input
    outputs = output
)

model1.summary()

from keras import utils

Now, let’s discuss the words whose location is interpretable within the embedding.

In the left region around (-5, 0), there seems to be a cluster of words with country names, such as north, myanmar, china south, us, ukraina, korea, brazil.

In the right region around (5,0), there seems to be a cluster of words about politican names such as hilary, trumpy, biden, ted, obama, bernie.

I think words that are related to real news are at the top because there are words like diplomats, steps, possible, asked, time, eye, serve, and account.

But the words that are related to the fake news are at the bottom because there are words like alleged, unreal, change, charged, fox, standing, humiliated, critics.
